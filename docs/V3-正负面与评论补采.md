# V3 Alpha 12：正负面、评论补采与游戏入口

版本 `3.0.0-alpha.12`，2026-10-08。继续使用一个业务主 Agent 和一个联网研究子 Agent，情报、素材、创意独立判断。本轮不删除文件、不发布或投放任何创意。

## 正负面规则

研究解读与主 Agent 判断增加有来源依据的 polarity（正面/正常中性/负面/正反争议/未知）和传播风险 level。区分事件属性与单条评论情绪，孤立差评不自动将正常游戏资讯判负面。

负面、混合争议、风险未明以及中高风险事件禁止生成增长创意与可传播素材。已知此类风险时，在模型调用前将 patterns 限为零、增长机会限为观察/归档，营销假设、承接、目标和上线条件字段必须为空。首次业务判断发现风险时再次拦截，不保存为可用素材。不能通过改名字、反转、去奖金或改成普通玩家继续借势。

游戏负面信号可作为中立监测情报，事实、传言和影响假设分开，不能用作推广素材。研究子 Agent 的判断不能被主 Agent 的正面措辞覆盖；只有完成主 Agent 或明确风险复核的正面/正常中性低风险事件可进入创意任务。研究阶段的单独判断不授权增长。

规则覆盖任务排队、领取、模型入口、制作修订、最终保存、素材复用、默认页面与日报/周报。风险记录按话题与来源 fingerprint 保存，替换记录存 topic_risk_revision。旧创意和素材原记录保留；停用草案只显示标题、原因与判断引文，原制作内容可在历史审计记录追查，不再列为当前可用交付。来源版本不同的旧创意也等待复核。

同一来源版本下已有负面/混合判断不能被研究刷新的正面措辞抹除；风险评估合并只保留有限公开判断，旧版本仍在历史表。

主 Agent 同一输入/提示版本再次判断时更新当前情报，原判断存 topic_intelligence_revision；避免纠错被 INSERT OR IGNORE 静默丢弃。历史素材、信号和任务均保留，当前展示按最新业务判断去重。

## 评论补采

先调用已有公开评论接口。接口失败、退避或未取得样本且预算仍有余量时，使用 read_comments_visual：隔离浏览器先定位评论容器，向下滚动触发懒加载，再将评论区滚到可见位置，最多三屏、十二条可见一级评论。支持开放 shadow DOM，不登录或穿透验证码。

能读取评论 DOM 就读取文字；评论内容框存在但正文文本不可取时，对截图中的该框做本地中文 OCR。OCR 只取框内词坐标，不把页面导航、推荐、日期或广告当评论。截图前后评论布局变化则放弃该段识别。保留 capture_id、原屏序号、位置、原图指纹、采样方法与日期原文；没有可靠绝对日期/作者时保留未知，不把截图时间当发布日期，不能据此证明旧内容近期翻红。

评论保存为独立 evidence，与原帖关联，不覆盖帖子正文。缓存可跨话题复用并保留原截图。截图没识别出有效评论时不进入产品截图入口，失败和原图仍在审计记录。

真实公开页面有明确限制：B站实测已定位评论区域但评论一直未加载；TapTap农田分享页未找到可靠公开评论边界，保存了 capture_91760d374bc64a1f95602479586ab25b，新增评论为0。这不是采集成功。隔离浏览器测试页面另验证了向下滚动2143px后定位两条评论，其中一条为画布文字，Windows OCR识别为“想要联机和蓝图收藏功能”；这是工具验收夹具，不是生产网友评论。

## 游戏内容与统计

发现页新增“近期游戏与玩家动态”。游戏媒体资讯与TapTap玩家分享在没有热度证据时标为游戏情报线索，不能伪装热点。“已解读且有热度依据”“当前页候选”“待自动初筛”分别显示数量。

界面验收时，近七天有发布日期的游戏渠道来源64条（游戏媒体37、TapTap27），游戏入口6条，当前游戏情报7条；只有3条具备现有解读和热度依据的热点。数字是该时点的有限渠道覆盖，搜索命中、评论、未知日期榜单词均不计入64条。B站游戏榜此时没有进入该发布日期窗口的记录，不能因此声称游戏全网覆盖充分。

自动筛选优先名额根据实际游戏渠道分配，不把B站全站热门全部当游戏。深度研究预算允许同时保留一个游戏直接相关任务与一个有依据的通用表达任务，仍从各领域发现。默认游戏情报只显示当前来源、最新业务版本；旧版本保留在审计库。

## 后续优先级

1. 扩大近期游戏来源，补官方公告、社区真实活跃讨论；渠道采集健康与内容可用率分别计量。当前13条连接器不等于全网。
2. 按主体、行动、发生时间与来源关系聚合同一事件及后续；语义相似只召回，不能将同游戏的不同事件硬并。增量评论进入新的解读/业务版本与风险重评还需继续细化。
3. 提升评论区连接器和截图定位的真实成功率，补样本覆盖、时间核对与OCR抽查。没有样本就保留未知，不补造正反观点。
4. 创意绑定具体游戏、人群及已核实的社区承接动作；传言不能作为确认的卖点，游戏机制与素材使用条件要核查。创意去重、制作质量、停止条件和实际收藏/参与反馈仍需磨合。
5. 建立真实样本回归集，分别评估热点标题可读性、跨源归属、时效、负面误放/误拦、情报独立价值与创意可执行性；最终增长仍需真实小实验验证。
