# V3 Alpha 14：GitHub 网站与成果同步

网站地址：[TapTap 情报与素材 AI](https://hccccc01333.github.io/taptap-hotspot-intel/)。代码仓库：[taptap-hotspot-intel](https://github.com/hccccc01333/taptap-hotspot-intel)。

代码和业务成果分别更新。`main` 中的前端、版本号或 Pages 工作流发生变化后，GitHub Actions 安装锁定依赖、检查 TypeScript、构建并发布网站。`site-data` 是独立的数据分支，只保存 `public-results.json`；本地后台每五分钟检查成果变化，变化后通过 GitHub Contents API 保存新版本，无变化时每小时保存一次运行心跳。同步使用本机 GitHub CLI 的登录凭据，不把凭据写入源码或前端。

网站每分钟重新读取最新成果，不需要重新构建页面，也不需要访问本机端口、登录或点击生产按钮。正常页面仍只有热点发现、事件跟踪、情报档案、素材库、增长创意。分类先展示卡片，详情点开；机会可回到对应解读和来源。

## 公开范围

`agent_v3/public_site.py` 在一致的 SQLite 读取事务中导出当前可用成果：有热度依据的解读、近期游戏解读、当前游戏情报、通过使用就绪与风险判断的素材、当前允许推广的创意。旧创意使用其交付时的事件版本判断，后续事件更新不会自动使旧创意恢复可用。导出保留可编辑原创正文、脚本、执行步骤、适用条件及来源链接。

不导出 SQLite、原始正文、完整评论、账号身份、截图、模型调用、密钥、推理过程、后台设置或本地路径。来源引用只保留短片段，公开素材的来源表达截断；原创交付正文保留完整。来源 URL 移除身份与认证参数。完整溯源仍在本地档案中保存。公开数据分支不会覆盖本地 Git 工作目录。

## 运行边界

GitHub Pages 负责网站展示，[不运行 Python 服务](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。当前采集、浏览器、OCR 和模型任务继续在本地后台运行。电脑关机或后台停止后，网站仍展示最后一次成果；同步超过90分钟时提示内容尚未更新。它不是云端全天候 Agent 部署。

首次部署配置 `VITE_PUBLIC_RESULTS_URL` 仓库变量，值指向数据分支中的公开 JSON。`VITE_API_BASE_URL` 留空，不暴露 localhost；`VITE_DEMO_MODE=false`，公开 V3 不使用合成演示数据。将来迁移到常驻服务器时，可以关闭公开数据模式并连接 HTTPS API。

本地 `settings.public_site` 保存目标仓库、`site-data` 分支、启用状态和下一次检查时间；`public_site_state` 保存成功时间、内容摘要和提交号；失败只保存错误类型并在下一轮重试，不保存可能包含凭据的命令输出。GitHub 的网络或权限失败不阻断采集和研究。
