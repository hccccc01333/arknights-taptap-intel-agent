# V3 Alpha 6：跨领域来源与正文积累

本轮补齐非游戏来源的发现、正文补读和可检索来源素材。它是持续情报系统的一层改进；尚不能据此认定增长创意质量或全网覆盖已经完成。

## 已实现

- 在已有十个渠道之外，接入中新社社会、文娱、生活三个官方公开 RSS。来源地址来自 [中国新闻网 RSS 订阅页](https://www.chinanews.com.cn/rss/)，按真实发布日期与原文地址保存。文娱渠道同时出现在文化和娱乐筛选中，领域标签来自栏目，不冒充 AI 分类。
- 新闻订阅的列表顺序不写成热度排名，候选标明“新闻发布，尚未证明热度升温”。只有近 48 小时发布且没有未来时间异常的新闻进入近期候选；缺失日期与旧闻保留为资料。重复采集不能令旧闻重新成为近期热点。
- 读取中新社文章的明确正文区域，最多保存 6000 字片段，记录实际跳转地址、截取状态、解析版本与未读取评论。正文/摘要分别保留素材版本，不把文章正文等同于已核实的用户反应。
- 读取贴吧公开热点页的平台话题简介，范围为 `topic_description`。它是平台编辑文本，不能冒充帖子正文、用户评论或情绪样本；不读取验证页面，不绕过安全验证。
- 每周期最多六次详情读取，按不同来源持久轮换，避免仅补读队列前列游戏内容。成功六小时内保留正文，失败半小时后重试；403/412/429 后本轮停止继续请求同类详情。补读不依赖模型，也不依赖研究开关。
- 实际读取状态、范围、原文时间、长文截取与失败原因进入候选详情及运行页面，正文带入情报任务包。紧凑情报契约为 `intelligence-v3.4`，旧任务/情报作为历史保留。来源地址或发布日期变化也更新候选指纹。

公开读取限定已经核对的 HTTPS 域名，逐次检查重定向、响应大小和总时间，不使用登录凭证。未取得可靠区域时保留原标题与摘要，不以空结果替换已有文本。

## 验证与边界

153 项本地检查和 TypeScript 通过；测试覆盖新闻日期和热度区别、域名/重定向限制、实体声明、正文大小与截取、跨领域筛选、轮换与缓存、内容版本/素材留存、失败停止和工具选择。模拟正文只存在测试内存库，不作为生产成果。

开发前的真实源验证取得三份 RSS：社会 30 条、文娱 30 条、生活 4 条；这些包含不同发布日期，不能全部称为当前热点。文娱文章明确正文读取成功。贴吧公开热点页可取得简介，跟进帖返回 403 安全验证；B 站详情返回 412。评论样本仍未取得，不能生成评论情绪统计。

本轮不再请求已经确认额度耗尽的 Zen 模型，太空兔平台/密钥归属与上游 502 的问题仍未验证解决。未自动切换模型，不把采集条数、单元检查或新增选项称为自动增长创意。

后续仍需：多种独立非游戏来源、跨平台同一事件的语义归并、持续传播证据、可靠讨论样本、素材制作与复用检索，以及模型可用后的真实机会到完整创意验收。
