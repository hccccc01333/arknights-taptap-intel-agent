# V3 Alpha 15：内容复用、时效与交付体验

本轮围绕已有成果的稳定性、可用性与溯源升级。用户确认模型余额耗尽，因此没有再次请求付费模型；质量验证使用已有真实档案与隔离测试模型，不把这些验证称为新的真实 AI 交付。

## 内容版本与热度观测分开

此前，榜单排名上升或渠道变化进入话题 fingerprint，可能让同一份正文的情报、素材和创意失效并重新排队。现在保存两个维度：

| 维度 | 内容 | 对业务结果的影响 |
| --- | --- | --- |
| 内容版本 | 来源标题、正文、URL、发布日期、研究证据及其关联状态 | 变化后重新判断，旧结果保存为历史 |
| 热度观测 | 同榜排名变化、渠道收录及相关观察信号 | 写入独立观测记录，保留原解读与业务成果 |

热点卡片分别显示解读时间和榜单观测时间。领域筛选使用当前热度观测；不会把更新的排名冒充重新完成的一次 AI 解读。

首次升级扫描仍重新计算旧版 fingerprint：仅在旧算法算出的版本确实相同时复用，不强行把所有旧产出标记为当前。这次迁移可能保守地使部分旧产出等待重新判断。后续同正文的普通排名变化不会重复建业务任务。

新增表 `topic_revision_state` 保存两个摘要与当前内容版本，`topic_observation_revision` 保存变化的热度观察。历史 topic、来源、解读和创意记录继续保留。

## 当前可用与历史档案分开

情报列表、传播素材和增长创意在读取时检查时效：近一周发布、已核实的近期事件时间，或有近期升温/讨论依据的旧内容，才能继续进入当前成果。只有重新采集旧内容或再次出现在榜单，不作为翻红证明。

过期的素材和创意退出当前可用列表，历史数据库保留；负面游戏情报可用于中立监测，负面、争议或风险不明事件继续禁止推广创意与传播素材。系统没有因为模型暂停而把旧素材自动包装成新成果。

## 打开、核查、带走

- 情报、素材和创意保持按用途分类，默认显示概要卡片。详情改为弹窗阅读，支持 Esc、关闭后返回原卡片焦点，以及手机窄屏。
- 搜索覆盖内容、场景和来源事件，提供游戏平台筛选及按整理时间/标题排序。卡片补充来源事件和整理时间。
- 素材可复制可编辑稿；创意可复制完整方案。Markdown 下载保留文案、脚本、执行方法、使用条件、待验证假设和来源链接。复制失败明确提示，不伪报成功。
- 来源入口优先显示平台、标题、日期和原始链接。引用编号仍作为内部索引，使用者无需先理解 hash 才能核查。
- 创意溯源按 `creative_id` 读取对应生成 run 的 event_version 和 evidence_version。原始机会判断与来源快照一起返回；事件后续版本另列历史，避免混成这条创意的原始依据。
- 公开投影新增引用来源索引与逐创意溯源。继续过滤正文、完整评论、截图、本地路径、账号、凭据及推理过程；保留短引用和原创交付正文。

这些按钮只用于阅读、核查和复制交付内容。正常页面仍没有采集、处理线索、启动研究或执行投放按钮。

## 额度暂停

DeepSeek 的余额不足状态写入持久 provider hold，按供应商模型别名共享。重启、原 402 退避时间到期或同供应商别名切换，均不会自行解除用户确认的暂停。模型构造与每次原生/工具调用前检查 hold；采集和已有成果同步继续。

本地及公开页显示“采集继续 · AI 整理等待额度恢复”。首次公开成果读取失败会自动重连，已有载入内容在短暂断网时可继续阅读。

恢复额度后，开发维护可明确解除暂停：

```python
from agent_v3.store import Store
from agent_v3.model import set_provider_hold, gate

s = Store()
set_provider_hold(s, 'deepseek-flash', False)
print(gate(s))
s.close()
```

这段维护操作没有调用模型。它不会擦除供应商仍有效的限流或 402 退避；只有 gate 变为 ready 后，后台才能继续模型任务。解除暂停需以用户后续确认额度恢复为准。本轮没有执行解除操作。

## 验证与边界

372项后端回归通过，其中新增14项覆盖排名变化与已完成任务复用、正文/发布日期变更、过期成果退出但历史保留、过期原生创意禁止模型调用、原始创意证据版本及缺失时阻断、持久额度暂停及批量来源接口边界。测试模型仅用于内存夹具。

TypeScript与679模块生产构建通过。本地真实档案浏览器验证五个入口、来源、复制、Markdown下载、弹窗关闭/焦点恢复及390px移动端；只有登录POST，没有启动采集或生成任务。公开页面与线上部署验收记录见[版本记录](版本记录.md)。

本轮没有提升模型本身的真实生成质量，也没有新增付费 AI 成果。事件语义聚类、评论覆盖、来源可信度分层、候选积压及持续无人值守质量仍需迭代。GitHub Pages继续承担公开阅读，本地后台继续承担执行；未迁移为常驻云端系统。
