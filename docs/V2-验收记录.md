## 真实模型测试的问题

- 固定免费模型曾成功调用工具，但反复读取与预算耗尽；已加入预算提示和收敛交付上下文。
- 旧搜索助手在 HTML 标记内截断标题，并丢弃互动计数；V2 直接读取完整返回字段。
- 缺失或截短的证据 ID 曾被当作空列表返回；现在显式拒绝并提示保留完整 ID。
- 模型网关等待心跳可使旧 socket 超时失效；V2 对响应加总时长限制，并测试心跳边界。
- Nvidia 免费服务返回过载或上游错误，其他免费模型和免费路由出现 HTTP 429；最终确认返回 `free-models-per-day`，即当天免费调用额度耗尽。部分早期响应无法形成有效工具决策。
- 本机 DeepSeek 凭证存在，但实测返回 HTTP 402，不能视为可用账户。
- 所有失败保留真实状态，不生成规则替代创意；当前实际模型交付仍为 0。
