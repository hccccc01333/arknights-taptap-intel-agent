# V3 Alpha 11：解读与业务产出质量

版本 `3.0.0-alpha.11`，2026-10-08。在已实现的自动研究链路上打磨解读、评论和业务判断，保留一个业务主 Agent 与所属研究子 Agent。

## 截图显示

解读页只展示成功读取且 OCR 成功、有文字的画面。浏览器留图但未执行 OCR、识别为空、访问限制或识别失败的截图不展示。数据库与原图保留，未删除文件。过滤后仍以原始 frame_index 取得原图，避免第2屏被误当第1屏。

OCR 成功不代表内容准确、相关或正文完整；来源关联仍由研究子 Agent 核对。原图与文字供核查，截图中的指令不生效。

## 评论与热点解读

便宜的程序过滤负责明显广告、起哄、重复与纯链接。短需求如“找普通人”“想要联机”不会因字数少而丢弃；重复按所属原帖判断，同样一句话在不同事件里仍可分别核查。旧长度标记在读取时重新评估，原话保留。

同一次研究子 Agent 任务评估评论是否采用、仅背景或排除，并返回简短原因。必须引用真实评论正文；有无效标记的评论不得用于观点，已知超过七天的评论只作背景。讨论焦点按主题概括，保留逐字引文及实际引用样本数，不计算总体情绪比例、不凑正反两方。评论全文默认折叠。

热点标题直接说明主体、行动和焦点。读取限制写到未知项，避免“正文只提”“截图显示”等过程描述成为标题。游戏术语或作者身份玩笑不能当作已核实的游戏变化或作者身份。

解读契约 `hotspot-interpretation-v3.11` 升级时重新评估旧缓存，旧解读存入 interpretation_revision；相同新版本继续复用。游戏情报与素材用途的新判断契约为 `intelligence-v3.7`。

## 三类独立产出

热点详情直接显示当前主 Agent 判断对应的游戏情报、可用素材、增长创意，含独立数量、内容、用途和保存/不保存的原因。旧判断和素材应用历史保留；同一素材再次使用有独立的 material_application_run，不误计成没有产出。

游戏情报需要带来源的具体变化或有限需求线索；普通发帖、游戏名玩笑不自动构成趋势。素材需具体玩家场景、可编辑表达和实际用法，区分原话、表达模式与原创改编。排行和销售数据不自动同时成为素材。

增长创意可以直接从有充分依据的近期热点提出。未验证的人群重合与效果明确为假设，可以形成小实验草案；不是一律搁置的理由。切口牵强仍需观察或归档。上线前条件仅列实际依赖：原创自摄零奖励方案不需要原视频授权或奖池；使用原片或奖励才分别核查。入口与产品能力未确认时列为条件，不假定已上线。

本轮回归检查包括：无效截图隐藏与原始索引、短需求与重复、评论引用真假、旧解读保留、新旧业务修订关联、素材单独产出、没有情报/素材也可形成创意。真实运行与恢复结果记录在[版本记录](版本记录.md)，测试夹具不计生产成果。

制作内容可在保留已保存计划、来源版本和事件判断的前提下重新修订，检查七天时效并存入 creative_content_revision。旧稿及事件版本保留，创意ID稳定，不因文案改稿增加创意数量。当前素材库隐藏已修订的旧制作稿，原始材料记录仍可追溯。用户文案和旁白不写入口配置过程，未确认的实际链接使用 `{{TapTap承接链接}}` 占位，配置和授权条件放入制作备注。
