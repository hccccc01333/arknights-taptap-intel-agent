# Alpha21交付修复回测

这次先修工程故障，不重新包装Alpha20的负面实验结果。回测使用那轮已失败的Xbox PC客户端、R6手游停运线索；它们已参与过开发诊断，属于定向回归，不能当作未见过的正式样本或架构优越性的证据。A/B/C仍共用相同初始线索，日期为空的输入没有人工补值，模型不获得核验基准。

## 实际变化

主Agent先明确是否值得查证游戏变化、玩家问题、表达或事件。是否能形成TapTap增长机会留到业务判断阶段；有具体游戏变化不必先证明热度或增长承接。没有具体变化的普通游戏帖子仍可留观。负面游戏变化可形成风险情报，推广创意继续受拦截。

日期缺失的新闻须有近期渠道观测才进入待查候选。既有工具预算内补读原网页，来源发布字段用于确认内容时间；不是事件发生时间，不证明热度。补到旧日期就退出当前候选，未核实则不产出当下业务成果。模型选择空工具动作也不能跳过可补读的日期缺口。

解读只填当前契约允许的字段：没有补查任务就不填followup_answers，没有待核关系就不填relation_reviews；实体、关系与需求放knowledge内。引用仍用输入ref，错误反馈给出路径与约束，缺字段路径由可信Schema生成。最多两次调用与总时间预算不变，不自动删改模型JSON来通过验证。

## 第一批实际结果

独立目录`data/v3/experiments/go-longcat-2.5-preview-free-20261010-alpha21-regression`，哈希`8f3e59c850db385ea58a6c65cdca11e03d753a129696bdee65b4f51c2428d430`，源码清单对应之后发布的`410088d`；冻结时Git记录的父提交与工作区源码清单另存。LongCat关闭独立思考，8192输出预算，每批80次调用／100万token，不使用付费替代。

六组全部执行。A/B各两份报告；C的Xbox线索交付一条游戏情报、无素材和创意，R6线索失败。Xbox解读和业务各经历一次maxItems引用数量错误，通过限定重试修正；未丢弃失败回答。第一批14次模型调用、60561输入token、9991输出token，用量均已知。边际token价格为零，不含Go订阅、工具成本；不能与Alpha20不同样本分母混成准确率对比。

R6已进入研究，不再被入口丢弃，但没有补到日期：3DM正文与文章头分开，发布时间位于news_warp_top。后续业务时间校验拒绝，异常退避又因隔离库没有登记外部模型配置而掩盖原错误。没有产出不能记作业务成功或正确风险拒绝。

补充文章头选择器，并只在实验的独立数据库登记同一已授权模型配置。已存原网页字节解析得到`2026-10-09T22:02:39+00:00`，即来源北京时间2026-10-10 06:02:39。依据为文章发布字段，非采集时间；未来的2027年停运计划仍是另外的日期。模型不获得手填的日期。

## 第二批与边界

修复后另建`go-longcat-2.5-preview-free-20261010-alpha21-regression-v2`，冻结哈希`2d739bde8edd5afce4891c40ccd8af49b2d4bac02e9f70754cc8429b9206dbd3`。源代码清单对应之后发布的`500d141`；代码、输入、授权重新冻结，第一批保持不变。

第二批六组全部执行，A/B各两份报告，C两组均失败。Xbox的knowledge/entities/5、R6的knowledge/entities/1两次都引用了不含实体surface原名的片段，严格证据校验拒绝，未进入业务判断。R6的真实正文读取已经补到`2026-10-09T22:02:39+00:00`，日期入口修复得到验证；图谱语义抽取仍阻塞整体解读，交付不稳定。无创意来自未通过研究，**不能据此证明负面增长拦截已真实验收**。14次模型调用，50234输入token、9830输出token，用量均已知，失败回答及校验路径保留。

目前只证明候选能进入研究、真实日期补查可运行，且第一批一例曾完成情报交付；未证明最新链路稳定。下一步应拆开事件解读与图谱抽取的交付边界：两者继续由同一个研究子Agent负责，已核验的事件正文不能因图谱抽取错误永久停住；无依据的图谱关系仍不得写入，图谱缺口明确记录并限额补查。这个改动尚未实现，也没有放宽本轮引用规则。

这两例只验证故障修复。事实、日期、无依据断言和引用语义仍需逐条复核；不证明素材、创意质量或TapTap商业增长，也不代表自然全网热点分布。正式后台的付费模型仍暂停，回测档案没有写进生产成果库，原始网页与最终回答保留在本地忽略目录。
