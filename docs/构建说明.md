# 构建说明：规格、Skill 与流水线

本文说明本仓库如何用 **提示词规格** 与 **[Agent Skills](https://agentskills.io)** 把「采集 → 标注 → 日/周报 → 跨渠道综合」做成可复现流水线。

Skill 目录：[`skills/`](../skills/README.md)。同一套 `SKILL.md` 可供支持 Agent Skills 的工具加载。

---

## 六步

```text
① 爬虫规格提示词  →  采集脚本 + crawl Skill
② 清洗+标注规格   →  LLM 结构化表
③ 错案改版        →  v1.4 annotate Skill
④ 报告写法 Skill  →  日/周报终稿
⑤ facts 锁数 Skill →  跨渠道综合
⑥ 脚本复现         →  看板 / 分析实验室
```

| 步骤 | 输入 | 产出 | 落点 |
|------|------|------|------|
| ① | 接口样本 + 字段规格 | 爬虫脚本 | `01爬虫/` · `arknights-taptap-crawl` |
| ② | 预处理规则 + JSON schema | 清洗/标注脚本 | `02数据/` |
| ③ | 错案 + 两段式规则 | prompt + Skill | `annotations_v1_4` · `arknights-llm-annotate-v14` |
| ④ | 四问法 / 薄样本规则 | 报告 Skill + 脚本 | `04日报周报/` · `arknights-taptap-yuqing-report` |
| ⑤ | facts 数字约束 | 跨渠 Skill + 脚本 | `09跨渠道AI/` · `arknights-cross-channel-facts` |
| ⑥ | 聚合刷新 | 看板 / 实验室 | `05` / `10` / `scripts/` |

```bash
python scripts/sync_agent_skills.py
```

## ① 爬虫

先用 F12 核对真实 JSON，再写字段规格（能取 / 派生 / 接口无则置空），交给 Agent 实现，并落到 Skill `arknights-taptap-crawl`。

```text
角色：数据工程师。实现 TapTap《明日方舟》评价爬虫（app_id=70253）。
证据：以仓库内接口 JSON 样本为唯一字段证据。
契约：每字段标注「直接取 | 派生 | 接口无（置空，禁止臆造）」；
X-UA 只读环境变量；遇 403/429/验证码停止或降速，不绕过。
MVP：review_id、正文、评分、时间、平台、游玩时长（可空）、点赞。
范围外：下载图片；用户画像；把接口 total 当全站总量。
验收：可翻页去重、可 checkpoint 续跑、有质检报告。
```

落点：`01爬虫/爬取提示词构建.md` → `crawl_taptap_reviews.py`

---

## ② 清洗与初版标注

```text
预处理：空正文删除；score_raw 禁止插补；时长空保留分层；箱线外评论默认不删。
标注：只输出 JSON；topic_primary∈8类+other；sentiment∈{正,中,负}；
actionable∈{是,否}；不确定→other+低置信；禁止编造版本/活动名；不要预测星级。
工程：Key 读环境变量；高推理；先小样本报告再扩量。
```

落点：`02数据/数据处理提示词.md` · `preprocess_reviews.py` · `annotate_reviews.py`

---

## ③ 升级到 v1.4

单字段 `sentiment` 会误判高级黑与「好玩就是有点肝」。按错案拆成两段式，写入 Skill。

```text
① incongruity_cues → rhetoric / literal_sentiment
② intended_sentiment，且 sentiment = intended
rhetoric∈{none,sarcasm,gaoji_hei,fanchuan,template_praise}
日报主指标只用 sentiment；rhetoric 进复核专栏。
```

落点：`02数据/annotate_reviews.py` · `skills/arknights-llm-annotate-v14/`

---

## ④ 日周报 Skill

```text
四层：信息 → 分析 → 判断 → 建议
四问：发生了什么 → 为什么 → 接下来怎样 → 建议怎么做
摘要四句：【数据洞察】【热点追踪】【风险预警】【需要决策】
薄样本：n<30 滚近 3 日；对照不足禁止 Δpp
```

落点：`skills/arknights-taptap-yuqing-report/` · `04日报周报/build_skill_reports.py`

---

## ⑤ 跨渠道 facts 锁数

```text
只能使用 facts JSON 中的数字与原话。
跨渠道比例只作结构对照，禁止写成全网 KPI。
校验失败 → 重试 → 模板降级（数字仍来自 facts）。
```

落点：`skills/arknights-cross-channel-facts/` · `09跨渠道AI/`
