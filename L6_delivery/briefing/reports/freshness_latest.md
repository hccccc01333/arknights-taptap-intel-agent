# 时效指标（H2）—— 从话题出现到判出迁移，滞后多久

- 采样间隔基准：**15 分钟**（来源：scheduler.PROBE_INTERVAL_MIN）
- 在追踪话题：19 个；其中**发生过状态迁移的 0 个**（其余 19 个还没动过）

- ⏳ **样本不足**（0/5 条迁移记录）——先让它跑够，再回来读结论。

> 为什么要有最小样本：首日采样时所有话题的 `state_changed_at == first_seen_at`（还没迁移过），
> 此时滞后恒为 0，不能据此说「时效很好」。**样本够之前不给结论。**


## 边界

- 时滞字段来自 `topic_state`；判定与采样都影响它，本报告只做呈现。
