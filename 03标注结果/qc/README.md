# 标注质检（人工金标）

对 `annotations_v1_4.csv` 做 **n=100** 分层抽检，算情绪 / 修辞一致率。

## 怎么填（中文下拉）

打开 **`qc_blind_to_label.xlsx`**：

1. 看「填写说明」页  
2. 到「盲标」页，用下拉选中文选项  
3. `gold_note` 可选手打  

| 列 | 下拉（中文） |
|----|----------------|
| `gold_sentiment` | 正 / 中 / 负 |
| `gold_rhetoric` | 无修辞 / 讽刺 / 高级黑 / 反串 / 模板好评 |
| `gold_note` | 无下拉，可选备注 |

**标注时不要打开** `qc_with_model.csv`。

打分时会自动把修辞中文映射成英文码（`none` / `sarcasm` / …），并写出 `qc_gold_normalized.csv`。

---

### 口径速查

| 情绪 | 什么时候 |
|------|----------|
| 正 | 真心喜欢 / 夸为主；夸中带一点槽也仍偏正 |
| 中 | 好坏对半、或模板敷衍好评说不清 |
| 负 | 劝退/退游/辱骂；五星正文在骂 → 负 |

| 修辞（中文） | 什么时候 | 内部码 |
|--------------|----------|--------|
| 无修辞 | 正常夸或正常骂（默认；拿不准选这个） | none |
| 讽刺 | 反话、阴阳 | sarcasm |
| 高级黑 | 整段像夸、细节全是骂 | gaoji_hei |
| 反串 | 假人设/假好评（慎用） | fanchuan |
| 模板好评 | 机械排比式好评 | template_praise |

普通差评 = **负 + 无修辞**（不是「讽刺」）。

## 填完后

```bash
python 03标注结果/qc/score_qc.py
```

会：① 中文→英文码转化 ② 算一致率 ③ 写出 `reports/qc_v1_*.md`。

## 重新抽样

```bash
python 03标注结果/qc/make_qc_sample.py --n 100 --seed 42
```

会覆盖盲标表；已开始填写请先备份。
